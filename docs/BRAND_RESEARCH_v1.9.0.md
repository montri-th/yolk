# Yolk 1.9 · Brand profile และเกณฑ์เริ่มต้น

> ตรวจหลักฐานวันที่ 7 ตุลาคม 2026 · 3 อุตสาหกรรม · 37 แบรนด์/นิติบุคคล · Nonbank เฉพาะ 10 รายที่เลือกได้

เราเริ่มจาก **แบรนด์ขายอะไร → อยู่ในตลาดย่อยไหน → เลือกข้อมูลอะไรไปคัดพื้นที่ → ไปตรวจอะไรต่อ** ค่าเริ่มต้นช่วยให้เปิดระบบแล้วเห็นคำตอบได้ทันที แต่ยังเป็นสมมติฐานของ Yolk ที่แบรนด์ปรับเองได้ ไม่ใช่สูตรที่บริษัทเหล่านี้รับรองหรือโมเดลที่เทียบยอดขายแล้ว

## อ่านผลวิจัยให้ตรงความหมาย

- **Positioning** ในเอกสารนี้คือสิ่งที่ผู้ดำเนินการสื่อสาร ไม่ใช่ผลสำรวจว่าลูกค้ามองแบรนด์อย่างไร
- **Submarket** ที่วัดได้ทันที: Grocery ใช้รูปแบบร้านในต้นทาง; Fuel เป็นสถานีเชื้อเพลิงรวม; Nonbank ใช้ขอบเขตใบอนุญาตระดับบริษัทเป็น proxy และต้องแสดงข้อจำกัด
- **Segment gap** ยังต้องรู้สินค้าที่สาขามีจริง ชั่วโมงเปิด กลุ่มลูกค้าที่ใช้บริการ และความต้องการที่ยังไม่ถูกตอบโจทย์ การไม่มีชื่อแบรนด์ในพื้นที่ยังไม่พิสูจน์ช่องว่างของกลุ่มลูกค้า
- **กลยุทธ์** เป็นชั้นหลังคัด Demand ไม่เปลี่ยนจำนวนไข่แดง และไม่ตัดสินว่าทำเลคุ้มลงทุน
- **ไม่เกิน 3** ในแต่ละจุดเลือก: กลุ่มปัจจัย Demand สูงสุด 3 กลุ่ม แต่ละกลุ่มมีตัววัดไม่เกิน 3; Supply ไม่เกิน 3; Strategy ไม่เกิน 3

## สิ่งที่ต้องเพิ่มในเฟสถัดไป

เพิ่มทะเบียน anchor POI พร้อมพิกัด ประเภท วันอัปเดตและ evidence; โรงพยาบาล/โรงเรียนเหมาะกับการขยายอุตสาหกรรมในอนาคต แต่ไม่ควรทำสีว่าเหมาะอัตโนมัติโดยไม่มีข้อมูลการเข้าถึงและภารกิจของลูกค้า สำหรับ 3 ธุรกิจปัจจุบันให้เริ่มตรวจโรงงาน ที่พัก ร้านอาหาร/ผู้ประกอบการ แหล่งชุมชน และบริการรถที่เกี่ยวข้องก่อน

เพิ่มข้อมูลในแต่ละสาขา: format/สินค้าที่มีจริง/วันเวลาเปิด/ทางเข้า/กลุ่มลูกค้าจากหลักฐาน แล้วจึงคำนวณ segment gap ได้ ใช้ profile นี้เป็นแบบฟอร์มเริ่มต้น ไม่ใช้แทนผลสำรวจ
