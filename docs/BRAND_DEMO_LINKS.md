# Yolk — Demo permalink ของแต่ละแบรนด์

ลิงก์เหล่านี้เปิด “โอกาสขยาย” ด้วยแบรนด์และ format สำคัญจาก preset เดิม ไม่มีเลขรุ่นใน URL จึงใช้ส่ง prospect ได้ต่อเนื่อง ใช้ Snapshot CityMETER ที่แสดงวันและข้อจำกัดใน demo; ไม่ใช่ข้อมูล live หรือคำรับรองผลธุรกิจ

เปิดลิงก์เป็นมุมมองส่วนตัว ไม่แก้เกณฑ์ทีม ไม่สร้างกิจกรรม และไม่ลบร่าง/shortlist/สาขาที่เคยบันทึกไว้ หากเคยมีเกณฑ์และร่างของแบรนด์/format นั้น ระบบใช้ค่าที่บันทึกไว้พร้อมแจ้งให้ทราบ ลอง preset จากปุ่ม “ลองเกณฑ์ตั้งต้น” ได้โดยสร้างร่างที่ตรวจผลก่อนยืนยัน

## วิธีใช้และข้อจำกัด

- ปุ่ม “คัดลอก Demo แบรนด์นี้” ในตัวเลือกแบรนด์ส่งเฉพาะ brand alias และภาษา พร้อมหน้าโอกาสขยาย ไม่ส่ง draft, team data, filter หรือค่าของลูกค้า
- เพิ่ม `&lang=en` หรือ `&lang=th` ก่อน `#market` เพื่อกำหนดภาษา; ใช้ `#demand` / `#supply` / `#criteria` / `#targets` / `#feed` เพื่อเข้าหน้าหลักอื่นที่อนุญาต
- รองรับ identity ID เดิมที่ percent-encoded เช่น `?brand=grocery-brand%3ATOPS#supply` แต่ลิงก์ที่คัดลอกจะใช้ alias อ่านง่าย
- ไม่รองรับ arbitrary route, external redirect, industry/scope ขัดกับ brand, query ซ้ำหรือ malformed encoding; เปิดบริบทเดิมที่ตรวจแล้วพร้อมคำแจ้งที่ไม่สะท้อนข้อความ input อันตราย
- ยอดในตารางมาจาก `countryDimensionCounts` โดยตรง พิกัดเป็นอีกชุดหลักฐาน ไม่รวมพิกัดเพื่อสร้างยอดสาขา; ไม่มีแบรนด์ที่สร้างยอดศูนย์เพื่ออ้างว่ามีข้อมูล
- Non-bank เป็นนิติบุคคลใน source ไม่ถือว่าทุกชื่อเป็น trade-brand ที่ตรวจยืนยัน; ชื่อและเลขบริษัทผูกตาม registry เดิม
- Preset เชิงตัวเลขเป็นสมมติฐาน Yolk ไม่ใช่เกณฑ์ที่ operator รับรอง และไม่มี SLA เรื่องอายุ URL หาก identity source ถูกถอนในอนาคต จะเก็บ safe unavailable notice แทนแต่งข้อมูล
