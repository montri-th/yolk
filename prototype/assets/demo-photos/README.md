# Branch photo mockups

Five AI-generated fictional fuel-station examples for the public CityMETER: Yolk branch editor. They are not photographs of Bangchak or any real station. The five views are independent mockups; they are not a verified photo set of one property.

Labels: frontage, entrance and exit, pumps and canopy, shop, forecourt. Each UI card identifies the picture as a mockup.

Generated with the built-in imagegen tool. Composition was inspected; runtime JPEGs were encoded at a 1,280 px long edge and quality 75 with sips. Original images are retained outside this published bundle. Exact artifact hashes and prompt specifications are in `manifest.json`.

Do not use these images as field-survey evidence, verified branch media, or as an assertion of branding. Replace with enterprise-authorized uploads when implementing production photo storage.
