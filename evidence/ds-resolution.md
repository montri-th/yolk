# Landometer DS authority for this public Yolk preview

The preview pins **Landometer Design System 0.9.4**, authoring revision `0.9.4-r2`, ruleset `lds-rules-0.9.4`, and machine package `v0.9.4-mp1`. The package checksum index SHA-256 is `9a261eb4df7bf3be5cf1e23f7fb2bd7079c67ca481fc55dccc7049ac52d325cc`. The runtime file hashes, roles, load order, and font licences are recorded in [DS_ASSET_INTEGRATION.md](../DS_ASSET_INTEGRATION.md), [the machine asset manifest](../contracts/ds-assets.v1.2.json), and [the runtime receipt](ds-runtime-assets-receipt.json).

This repository includes an artifact-specific, proportional web derivative of the Landometer logo on a light plate. Its original full-resolution source PNG is a **reference-only** manifest entry and is deliberately absent from the public tree. The current Yolk preview handoff does not amend the DS registry or grant a reusable app-header identity role to another product. Before a production identity release, record the product role, carrier surface, rights, clear space, and minimum size.

The exact colour CSS and fonts are DS runtime assets. `fonts.css` and `yolk-analytical.css` are Yolk adapters and are identified as such. Static `dial-quiet.svg` is decorative on Brand Blue only; motifs are not logos or data marks. Analytical class thresholds and missing-data semantics belong to the product contract, not the DS asset package.

Asset hashes and code syntax were checked. Rendered/browser visual QA remains pending; see [HANDOFF.md](../HANDOFF.md#verification).
