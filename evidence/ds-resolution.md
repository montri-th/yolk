The runtime file hashes, roles, load order, and font licences are recorded in [DS_ASSET_INTEGRATION.md](../DS_ASSET_INTEGRATION.md), [the machine asset manifest](../contracts/ds-assets.v1.3.json), and [the runtime receipt](ds-runtime-assets-receipt.json).

This repository includes an artifact-specific, proportional web derivative of the Landometer logo directly on the existing light page surface, with no frame or artificial backing. Its original full-resolution source PNG is a **reference-only** manifest entry and is deliberately absent from the public tree. The current Yolk preview handoff does not amend the DS registry or grant a reusable app-header identity role to another product. Before a production identity release, record the product role, carrier surface, rights, clear space, and minimum size.

The exact colour CSS and fonts are DS runtime assets. `fonts.css` and `yolk-analytical.css` are Yolk adapters and are identified as such. Yolk removes all motifs from the runtime by owner instruction. Historical motif hashes remain reference evidence only. Dark mode uses the approved governed live-text identity, with no invented inverse image. Analytical class thresholds and missing-data semantics belong to the product contract, not the DS asset package.

Asset hashes and code syntax were checked. Rendered/browser visual QA remains pending; see [HANDOFF.md](../HANDOFF.md#verification).
