# CityMETER: Yolk

[เริ่มที่นี่](START_HERE.md) · [Demo ทุกแบรนด์](https://montri-th.github.io/yolk/brands.html) · [Permalink ทั้ง 37 แบรนด์](docs/BRAND_DEMO_LINKS.md)

เครื่องมือคัด Demand สูง เปรียบเทียบ Supply และเลือกกลยุทธ์เพื่อเตรียมสำรวจทำเล สำหรับ Fuel, Grocery และ Non-bank รุ่น 1.9.11 เพิ่มขีดจำกัดโลโก้เป็น 500 จุด / 250 จุดเมื่อแผนที่แคบ เพิ่มลิงก์ทดลองใช้เฉพาะแบรนด์ ปรับ Activity ให้อ่านข้อความยาวได้ และอธิบายบทบาท Demand กับกิจกรรมเสริมให้แยกกันชัดเจน โดยคงข้อมูลและเกณฑ์เดิม

**สถานะเอกสารรอบนี้:** implementation พร้อมสำหรับการตรวจรวมปัจจุบัน; final QA, ZIP closure และการเผยแพร่ 1.9.11 ต้องยืนยันจาก receipts จริง ไม่ยกผล 1.9.10 มาเป็นผลรุ่นนี้ [เว็บรุ่นที่เตรียมเผยแพร่](https://montri-th.github.io/yolk/?v=1.9.11#market) และ [Release ที่ต้องตรวจหลังเผยแพร่](https://github.com/montri-th/yolk/releases/tag/v1.9.11) เป็นปลายทางที่ตั้งใจใช้ ไม่ใช่หลักฐานว่าพร้อมแล้ว
